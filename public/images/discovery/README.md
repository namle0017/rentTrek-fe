# Discovery page image assets

The equipment photos in this folder were extracted from the user-supplied design reference `home-gear-discovery.png` to reproduce its visual design. Product names, offerings, prices and IDs still come from the API.

The hero uses a clean mountain photograph because the reference banner has text embedded in the image: https://unsplash.com/photos/photo-1464822759023-fed622ff2c3b (image source: https://images.unsplash.com/photo-1464822759023-fed622ff2c3b).

`ProductImage` substitutes photos only for the original local demo illustrations (tent, backpack and sleeping bag). Custom product image URLs remain unchanged. The other equipment photos are available for future catalog content.

The Be Vietnam Pro typeface is stored locally in `public/fonts`; its license is included there.
